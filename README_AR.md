# MILO ADMIN SYSTEM V3 — نفس دخول كاشير ميلو

## تسجيل الدخول
يستخدم نفس `username` و`password` المسجلين في ورقة `Accounts` الموجودة في جدول Google Sheets الخاص بـMILO CASHIER. يتحقق الخادم من حالة الاشتراك (`status`) وتاريخ انتهائه (`subscription_end`) ويستخرج `store_code` من الخادم، وليس من المتصفح. **لا تنشئ مستخدمًا إداريًا منفصلًا ولا تضع بيانات الدخول في HTML.**

## التثبيت الصحيح (بدون إيقاف الكاشير)
1. أنشئ مشروع **Apps Script جديدًا ومستقلًا** عن Apps Script الخاص بالكاشير، فلا تستبدل كود المبيعات الأصلي.
2. انسخ `AppsScript/Code.gs` و`AppsScript/Bridge.html` إلى المشروع الجديد (`Bridge` ملف HTML).
3. من Project Settings > Script properties أضف:
   - `SPREADSHEET_ID`: معرّف ملف **Google Sheets نفسه** الذي يحوي ورقة `Accounts` في الكاشير.
   - `ALLOWED_ORIGIN`: أصل موقع GitHub Pages مثل `https://USERNAME.github.io` (بدون `/repo` وبدون شرطة أخيرة).
4. نفّذ `checkAdminSetup` مرة واحدة لمنح الصلاحيات وإنشاء ورقة `MiloAdminDevices` إن لم توجد.
5. انشر Web App من المشروع الجديد بصلاحيات `Execute as me` و `Anyone`؛ والحماية الحقيقية للطلبات تتم داخل `adminCommand`.
6. ضع رابط `/exec` **الجديد** في `config.js`. الرابط السابق في الملف رابطك القديم، ولا يُتوقع أن يعمل مع الجسر الجديد قبل نشره بالشكل الصحيح.
7. ارفع ملفات واجهة الإدارة على GitHub Pages، ثم سجّل الدخول بنفس حساب MILO CASHIER.

## حفظ البيانات والحماية
- **الأجهزة** تحفظ على نفس Spreadsheet في ورقة `MiloAdminDevices`، ويتم عزل كل جهاز حسب `store_code` على الخادم. أي محاولة تعديل سجل متجر آخر سترفض.
- **الأقسام الأخرى** مثل الموظفين والمنتجات والفواتير والمصروفات ما زالت بيانات **محلية في متصفح الجهاز فقط**، وليست بيانات الكاشير السحابية. أصبح مفتاح التخزين منفصلًا لكل `store_code` بعد نجاح تسجيل الدخول؛ لكنه لا يمنع وصول أشخاص لديهم وصول فعلي إلى ملفات المتصفح إلى البيانات المحلية.
- ليست هناك مراقبة اتصال فعلية أو قفل للأجهزة عن بعد في لوحة الإدارة هذه.
- في هذا الإصدار يحاكي الخادم مقارنة كلمة المرور النصية التي يجريها كود الكاشير الأصلي. يوصى لاحقًا بترقية نظام الدخول في الكاشير والإدارة معًا لتخزين كلمات المرور مجزأة وتفعيل جلسات محدودة الصلاحيات.
- لا تضع كلمات المرور في كود المصدر أو مشاركات الدعم. ولم نختبر نشر الكود أو الدخول إلى حساب حقيقي.
- إذا كانت ورقة `MiloAdminDevices` موجودة من إصدار أقدم بدون عمود `store_code` سيوقف الخادم الوصول إليها لحماية عزل المتاجر. خذ نسخة احتياطية ثم أعد تسميتها قبل تشغيل النسخة الجديدة؛ لن تُحذف تلقائيًا.
