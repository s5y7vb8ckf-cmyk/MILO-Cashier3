# ميلو للإدارة — MILO ADMIN SYSTEM

برنامج إداري عربي **مستقل** عن MILO CASHIER، يعمل بملفات HTML/CSS/JavaScript دون خادم أو Vercel.

## التشغيل
1. افتح `index.html` مباشرة على الكمبيوتر، أو ارفع **جميع الملفات والمجلدات** إلى مستودع GitHub Pages.
2. افتح رابط GitHub Pages على Chrome أو Edge. عند أهلية تثبيت الموقع كتطبيق، سيظهر زر التثبيت الأصلي في المتصفح.
3. أضف بيانات الموظفين والعملاء والموردين والمنتجات والفواتير والمصروفات والمهام.
4. من الإعدادات احفظ نسخة احتياطية JSON بانتظام.

## الوظائف
لوحة تحكم بمؤشرات، إدارة السجلات (إضافة وتعديل وحذف وبحث)، تصدير CSV لكل قسم، تقارير مالية مبسطة، متابعة المخزون والمهام، الطباعة، نسخ احتياطي واستعادة JSON، واجهة RTL متجاوبة، وأيقونات لتثبيت PWA.

## حدود هذا الإصدار — مهم
- البيانات تحفظ في `localStorage` **على نفس المتصفح والجهاز فقط**. لا تتزامن مع أي جهاز آخر أو مع MILO CASHIER.
- لا يوجد تسجيل دخول محمي أو صلاحيات متعددة أو قاعدة بيانات سحابية. **لا تصلح هذه النسخة لبيانات عمل حساسة أو تشغيل إداري متعدد المستخدمين** من دون خادم آمن وقاعدة بيانات وصلاحيات ونسخ احتياطية مؤسسية.
- الفواتير مجرد سجل إداري مبسط، وليست فواتير ضريبية إلكترونية معتمدة؛ لا تتضمن تكامل هيئة الزكاة والضريبة والجمارك.
- التقارير المحاسبية مؤشرات تقريبية وليست نظام قيود مزدوجة أو نظام ERP محاسبي معتمد.
- لا يلزم مفتاح API. لا تضع أسرارًا أو كلمات مرور في JavaScript العام على GitHub.

## تحديث البرنامج
بدل ملفات الموقع كلها عند التحديث. يمكن إنشاء نسخة احتياطية قبل أي تحديث. لا تحذف بيانات الموقع في المتصفح إذا أردت الاحتفاظ بالسجلات.
